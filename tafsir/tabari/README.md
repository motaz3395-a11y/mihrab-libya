# تفسير الطبري — جامع البيان عن تأويل آي القرآن

ملف لكل سورة (`001.json` … `114.json`)، يستخدمه تطبيق «مِحراب ليبيا» لعرض التفسير عند الطلب.
الصيغة: `{ "s": رقم السورة, "t": [نص التفسير لكل آية], "f": [هوامش التحقيق لكل آية] }` بترقيم آيات حفص.

- **المصدر:** مركز تفسير للدراسات القرآنية — طبعة دار هجر، تحقيق الشيخ عبد الله التركي وفريقه العلمي.
